# Medivin Clinic

A single-page Next.js website for Medivin Clinic in Manish Nagar, Nagpur. The site presents women’s health, pregnancy, newborn, and pediatric care with direct phone and WhatsApp appointment actions.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Validation

```bash
npm run lint
npm run typecheck
npm run build
```

Clinic facts are centralized in `src/data/clinic.ts`. Update that file when verified contact details, timings, services, or doctor information change.
